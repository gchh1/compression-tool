# GUI Windows (HTML-Rendered)

`src/gui/windows` contains GUI-side windows rendered through local HTML.

## What this directory is

- UI view generators used by desktop GUI dialogs/windows.
- HTML/CSS/JS rendering assets opened from local runtime.
- Part of GUI presentation layer, similar in role to widget dialogs.

## What this directory is NOT

- Not a web backend service.
- Not an HTTP API server.
- Not a browser-deployed frontend project.

## Naming note

The folder name reflects actual responsibility: these modules implement GUI windows.
