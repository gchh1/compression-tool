# 缩写对照表（compression-tool）

本文档登记代码与设计中出现的**缩写标识**及其中英文含义，便于阅读流式 / DPFlate / LZDP 相关实现。新增含缩写的公开 API、文件名或类型名时，请同步更新本表。


| 缩写 / 标识                 | 英文展开                                          | 中文说明                                                                        |
| ----------------------- | --------------------------------------------- | --------------------------------------------------------------------------- |
| **DP**                  | Dynamic Programming                           | 动态规划；在压缩里指按字节位置做最优代价推进。                                                     |
| **DPFlate**             | DP + (FLATE-style bitstream)                  | 本项目中结合 DP 匹配决策与类 DEFLATE 熵编码的算法名；**非**标准 zlib 的 Deflate。                    |
| **DP Core**             | DP Core (pure DP step)                        | 设计文档中的「仅做 DP、不感知 I/O」的内核边界；与 Huffman / temp 写盘解耦。                           |
| **FLATE**               | (LZ77 + Huffman) style                        | 两棵 Huffman 树（字面量/长度 + 距离）的经典 DEFLATE 风格位流，与 RFC1951 Deflate 概念对齐但实现细节以代码为准。 |
| **3HfM** / **3HfMTree** | Three Huffman trees + Fixed-chunk Multi-level | 三树 Huffman + 固定槽宽多级编码的变体；与标准 FLATE 两树不兼容。                                   |
| **Huff** / **Huffman**  | Huffman coding                                | 哈夫曼编码；`huff_*` 前缀表示熵编码阶段（频率、建树、发码），实现集中于 ``src/algorithm/DPFlate.cpp``。 |
| **Streaming**           | Streaming state machine                       | 流式状态机驱动模式；如 `LZDP_Streaming`。                                               |
| **LZDP**                | LZ + DP                                       | 基于 LZ 风格匹配 + 动态规划选路的压缩族。                                                    |
| **LZ77**                | Lempel–Ziv 1977                               | 滑动窗口 + 回溯引用的字典压缩模型。                                                         |
| **KMP**                 | Knuth–Morris–Pratt                            | 字符串匹配算法；此处作匹配引擎选项之一。                                                        |
| **Ob** / **Lb**         | Offset bits / Length bits                     | 对 offset、length 的固定位宽或上界比特数（依上下文）。                                          |
| **EOB**                 | End Of Block                                  | Huffman 字面量/长度字母表中的块结束符号（常为 256）。                                           |
| **temp A** / **temp B** | Temporary file A / B                          | 流式管线中的临时文件：A 多为前向 DP 的紧凑链节，B 多为回溯后的 token 流（见设计文档）。                         |
| **WCX**                 | (project archive format)                      | 本项目打包/工作区相关容器格式（见 archiver / API 文档）。                                       |
| `dpflate_collect_input_one_index` | (free function, friend of DPFlate) | 定义于 ``src/algorithm/DPFlate.cpp``：COLLECT_INPUT 单步（push-DP + 写 temp A），对应设计文档 DP Core 单步边界。 |
| `lzdp_streaming_collect_one_index` | (free function, friend of LZDP_Streaming) | 定义于 ``src/algorithm/LZDP.cpp``：LZDP Streaming 的 Phase1 单步。 |
| **COLLECT_INPUT** / **BACKTRACK** / **BUILD_TREE** / **EMIT_TOKENS** | (state names) | 流式压缩设计文档中 DPFlate / LZDP Streaming 状态机阶段名。 |
| **KPI** (若出现)           | Key Performance Indicator                     | 关键性能指标。                                                                     |


### DPFlate 相关符号（实现中常见）


| 标识                                                            | 含义                                             |
| ------------------------------------------------------------- | ---------------------------------------------- |
| `SEARCH_SIZE`                                                 | 搜索窗口（字节）上界。                                    |
| `LOOKAHEAD_SIZE`                                              | 前瞻窗口（字节）上界。                                    |
| `MIN_MATCH`                                                   | 允许的最短匹配长度。                                     |
| `DP_TOP`                                                      | 每步保留的匹配候选数量上界（与 DP 分支因子相关）。                    |
| `DP_SUB_MATCH_MAX`                                            | 子匹配 / 链式枚举上的额外上界（实现参数）。                        |
| `spill_spec_`                                                 | **Packed DP link** 的位级打包规格（offset/length 位宽等）。 |
| `freq_map_`                                                   | FLATE 风格主 Huffman 字母表（含字面量与长度码）的频率表。           |
| `dist_freq_`                                                  | 距离 Huffman 字母表频率。                              |
| `literal_freq_3hm_` / `offset_freq_3hm_` / `length_freq_3hm_` | 3HfM 三树各自的频率向量。                                |
| `literal_run_len_3hm`                                         | 3HfM 回溯阶段对连续字面量的游程计数（用于游程头统计）。                 |
| `huff_reset_entropy_tables` / `huff_backtrack_accumulate_token` / `huff_backtrack_finalize_literals` / `huff_build_tree_and_write_trees` / `huff_emit_token_stream` | ``DPFlate`` 私有成员 | 熵层解耦入口，均在 ``DPFlate.cpp``，不单独建「流式子算法」翻译单元。 |


### 维护约定

- 新缩写首次出现在 **头文件 `public`/`protected` API** 或 **跨模块类型名** 时：在声明旁加一行 `///<` 或 `//` 注释，并追加本表一行。
- 仅函数体内局部变量使用的缩写（如 `ob`、`lb`）在函数头注释中解释即可，不强制入表，除非跨文件复用。
