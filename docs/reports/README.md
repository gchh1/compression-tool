# Reports Directory

Generated test outputs and benchmark run artifacts should be stored here.

## Layout

- `benchmarks/` - Persistent benchmark and comparison outputs.
- `debug/` - Ad-hoc debug/test command outputs.

## Rule

- Keep generated outputs inside `docs/reports/`.
- Do not place report `.txt` outputs in repository root.
- If a file is generated by executing tests/scripts, it belongs in `docs/reports/`.
