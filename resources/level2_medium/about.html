了解 WebCompress 项目的背景、目标与技术愿景

项目背景

WebCompress 是一个学术性质的数据结构课程设计项目，旨在通过实现经典的压缩算法（Huffman 编码、LZ77/LZSS 字典编码、Deflate 混合压缩）来深入理解数据结构在工程实践中的应用。

技术目标

  • 算法层面：完整实现 Deflate 压缩标准，包括 LZ77 滑动窗口匹配与 Huffman 变长编码两个核心阶段
  • 性能层面：通过哈希表优化匹配查找，将时间复杂度从 O(n²) 降低至接近 O(n)
  • 应用层面：构建完整的网页资源压缩系统，支持 HTML/CSS/JS/PNG/JPG 等多种文件类型
  • 扩展层面：提供 Python (PyQt6) 和 Web (WebAssembly) 双端绑定，实现跨平台使用

系统架构

本项目采用分层架构设计，底层为 C++ 核心引擎，上层为 Python/Web 绑定层。核心引擎包含以下模块：

algorithm 基础算法：Deflate, LZSS, Huffman, Delta
core 压缩器封装：DeflateCompressor, LZSSCompressor
preprocessor 预处理：Archiver 打包, ImageParser 图像解析
utils 工具类：BitReader 位读取, BitWriter 位写入
