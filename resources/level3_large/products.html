产品功能列表

Deflate 压缩引擎

LZ77 + Huffman 混合压缩算法，适用于通用文本数据。支持流式处理和分块编码。

LZSS 快速压缩

轻量级字典压缩算法，适合小文件和实时场景。低内存占用，高吞吐量。

Huffman 纯编码

纯 Huffman 变长编码器，适合高熵随机数据。提供完整的树序列化和反序列化能力。

图像 Delta 预处理

针对图片资源的差分编码模块，配合质量参数控制压缩效果与视觉损失的平衡。

多文件归档打包

自定义协议的多文件打包工具，支持魔数校验和顺序存储，便于传输和分发。

Python 绑定层

Pybind11 封装的 Python 接口，可直接在 PyQt6 GUI 中调用 C++ 核心压缩能力。
