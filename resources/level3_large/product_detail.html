Deflate 压缩算法详解

算法概述

Deflate 是一种结合了 LZ77 字符串替换和 Huffman 编码的无损数据压缩算法规范。它被广泛应用于 ZIP、GZIP、PNG 等格式中。本项目的实现遵循 RFC 1951 规范，并在此基础上进行了多项性能优化。

核心组件

  1. 滑动窗口 (Sliding Window): 维护最近处理的 32KB 数据作为字典，用于查找重复模式
  2. 哈希链 (Hash Chain): 使用 3 元组哈希函数快速定位潜在匹配位置
  3. 惰性匹配 (Lazy Matching): 在找到匹配后继续检查下一个位置是否有更长匹配
  4. Huffman 编码: 将 LZ77 输出的 Token 流转换为变长二进制编码

数据结构分析

窗口大小SLIDE_SIZE = 32768 (32KB)
总缓冲区WINDOW_SIZE = 65536 (64KB 双缓冲)
哈希表HASH_SIZE = 32768 (15-bit hash)
最大链长MAX_CHAIN_LENGTH = 256
最小匹配MIN_MATCH = 3
最大匹配MAX_MATCH = 258
Token 缓冲MAX_BLOCK_TOKENS = 16384
