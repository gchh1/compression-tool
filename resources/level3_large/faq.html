常见问题解答

Q: 支持哪些文件格式？
A: 支持 HTML, CSS, JavaScript, JSON, XML, SVG 等文本格式，以及 PNG, JPG, JPEG, GIF, BMP 等图片格式。
Q: 压缩是无损的吗？
A: 对于文本文件完全无损，解压后 MD5 校验一致。图片文件可通过 quality 参数控制是否允许有损。
Q: 最大支持多大的文件？
A: 理论上无限制，但建议单次压缩不超过 50MB 以获得最佳性能体验。
Q: 如何集成到我的项目中？
A: 提供 Python (pybind11) 和 WebAssembly 两种绑定方式，可在桌面应用或浏览器中直接调用。
Q: 与 gzip 相比如何？
A: 在典型网页资源上，我们的压缩率与 gzip -6 相当或略优，且提供了更丰富的 API 和可视化功能。
