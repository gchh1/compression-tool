核心技术特性

⚡

LZ77 滑动窗口压缩

32KB 滑动窗口配合哈希链快速匹配，将字符串搜索从 O(n²) 优化至接近 O(n)。最大链长限制 256，防止退化情况。支持最长 258 字节匹配，最小 3 字节触发阈值。

  • 窗口大小: 32KB (双缓冲 64KB)
  • 哈希表: 32768 条目 (15-bit hash)
  • 链长限制: MAX_CHAIN=256
  • 匹配范围: 3-258 bytes
🌳

Huffman 变长编码

基于优先队列构建最优前缀编码树。286 个符号的字母表覆盖所有字面值和长度码。树结构通过前序遍历序列化到比特流中，解压端无损重建。

  • 字母表: DEFLATE_ALPHABET_SIZE=286
  • 符号位宽: DEFLATE_SYMBOL_BITS=9
  • 序列化方式: 前序遍历 (0=内部, 1=叶子)
  • 编码缓冲: 64-bit bit buffer
📦

LZSS 字典压缩

优化的 LZ77 变体，输出格式为标志位+数据对。12 位偏移 +4 位长度编码，每 8 个 token 共用一个标志字节。字典大小 4095，适合中小型文本文件。

  • 字典大小: DICTIONARY_BUFFER=4095 (12-bit)
  • 偏移编码: 12 bits
  • 长度编码: 4 bits (+MIN_MATCH=3)
  • 最大长度: MAX_MATCH=18
🖼️

Delta 图像预处理

针对 PNG/JPG 图片的差分编码策略。利用相邻像素的空间相关性进行预测编码，配合可调 quality 参数实现有损/无损切换。STB 库解析 RGB 三通道数据。

  • 通道数: DESIRED_CHANNELS=3 (RGB)
  • 质量参数: 0-100 (shift 计算)
  • 图像库: stb_image / stb_image_write
  • 处理流程: parse → Delta encode → compress
